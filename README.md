# Seventeen Syllables of Debugging

An entry for the make.fun haiku contest about debugging. The haiku is a
5-7-5 poem built around one concrete scene: the cursor blinking at three in
the morning beside a failing test. The last line flips the point of view,
because the bug turns out to be the author's own code from last week.

I wrote six candidates (printf logging, a rubber duck, a breakpoint, a stack
trace, a night ending at dawn) and checked each one's syllable count with a
vowel-group counter before choosing. They are all in `candidates.txt`.

## Run it

```
python3 main.py
```

This writes the haiku to `/output/entry.txt`. It is 71 characters, well under
the 200-character limit.
